# 신세계 백화점 키오스크 프로토타입

디자인 포트폴리오용 신세계 백화점 안내 키오스크 프로토타입입니다. 실제 서비스가 아니며, 입력한 정보는 어디에도 전송되지 않습니다.
Figma 화면에 그려진 **키오스크 기기(스탠드)까지 포함한 2521×1776 프레임 전체**를 구현했습니다. 브라우저 창 크기에 맞춰 기기째로 보입니다.

## 실행 / 배포
- 로컬: 이 폴더에서 `python3 -m http.server` 실행 → `http://localhost:8000`
- GitHub Pages: 이 폴더 내용을 저장소 루트에 올린 뒤 Settings → Pages → Branch `main` / `(root)` 선택 (`.nojekyll` 포함)
- 특정 화면 바로 열기: `index.html?s=8:295` (화면 id)

## 폴더 구조
```
index.html            시작 파일 (왼쪽 Flows · 처음으로 · 뒤로 · 연결 표시)
css/kiosk.css         레이아웃, 드롭다운, 접근성(고대비·낮은 화면·글씨크기), 호버
js/flows.js           Flows 목록 (Figma 플로우 시작점에서 자동 생성)
js/kiosk.js           라우터, 드롭다운, 접근성 옵션, 화면 맞춤
js/kenh.js            화면 키보드(한글 조합)와 검색
js/kswipe.js          터치·슬라이드(캐러셀, 팝업 넘기기, 페이지 넘김, 끌어서 스크롤), 글자 맞춤
js/kmap.js            지도 확대·축소·이동, 현재 위치 찾기
js/kres.js            화면 배율에 맞는 이미지 크기 선택 (js/imgsizes.js: 원본 크기 목록)
js/pages/*.js         Figma에서 자동 변환한 화면 32개
js/overlays.js        드롭다운 7종
js/hover.js, flowpanel.js, enhance.js   호버 표시, 반응형 Flows 패널, 입력칸 보완
assets/               이미지(WebP), 글꼴(Noto Sans KR·Inria Serif·Inter 등, 사용 글자만 담은 경량 파일)
tools/figma-kiosk/    Figma → 화면 변환 도구 (Figma 수정 시 재생성)
```

## 만든 방법과 정확도
PC 창처럼 작게 볼 때는 미리 고품질로 줄여 둔 이미지(assets/img/r/, 1/2·1/4·1/8)를 화면 배율에 맞춰 골라 써서 로고가 깨지지 않게 했습니다. 지도를 확대하면 다시 큰 이미지로 바뀝니다(js/kres.js, 이미지를 다시 만들면 `python3 tools/figma-kiosk/mkres.py` 실행).
화면을 창 크기에 맞출 때 CSS zoom을 써서, 작게 볼 때도 지도의 가는 선과 작은 글자가 흐려지지 않게 했습니다(zoom을 지원하지 않는 브라우저는 transform으로 맞춤).

Figma 레이어를 HTML/CSS로 변환했습니다. 글자와 버튼은 HTML, 아이콘은 SVG, 사진은 원본 이미지입니다.
색 필터가 걸린 사진 15장은 Figma가 그 레이어만 따로 그린 결과를 써서 색을 똑같이 맞췄습니다.
32개 화면 모두 Figma 렌더와 픽셀 비교 결과 차이가 4.5% 이하입니다(중앙값 3.1%, 대부분 글자 가장자리).

글꼴은 Figma에 쓰인 Noto Sans KR, Inria Serif, Inter를 그대로 넣었습니다. 구할 수 없는 글꼴은 비슷한 글꼴로 바꿨습니다(Arita Buri는 Noto Serif KR, Paperlogy는 Pretendard).
한글은 Figma처럼 글자 단위로 줄을 바꾸고, 크기가 섞인 문단도 Figma와 같은 줄 간격으로 맞췄습니다.

## 화면 흐름 (Figma 연결 그대로)
- 왼쪽 Flows: Figma 프로토타입의 플로우 9개를 순서 그대로 표시합니다(시작페이지, 메인페이지, 층별안내, 매장조회, fnb, 편의시설, 행사조회, 매거진, 목적선택). Figma를 다시 반영하면 `js/flows.js`가 자동으로 새로 만들어집니다.
- 화면 이동 연결 261개를 자동 클릭으로 검증해 260개가 통과했습니다. 남은 1개는 매거진 '처음으로'입니다. 같은 위치에 목적지가 같은 '처음으로' 버튼이 겹쳐 있어서 실제로는 정상 이동합니다.
- 드롭다운 연결 176개(언어, 음성크기, 음성속도, 글씨크기, 고대비, 낮은 화면)가 모두 열리는 것을 확인했습니다.
```
인트로 → 목적선택 → 매장안내(현재위치·층별안내 1F/B1/2F·근처 매장/행사 팝업)
                  → 매장조회(통합검색/카테고리/층별) → 매장상세 → 길안내(위치선택 → 경로 4종 ↔ 평면지도 → 앱으로 보내기)
                  → F&B(검색/카테고리 → 식당 상세) → 편의시설(1/2 → 2/2 → 음수대) → 행사(전시·팝업 3종) → 매거진(전체 이슈·프라다)
오른쪽 메뉴(층별·매장·행사·F&B·시설·매거진)와 '처음으로'는 모든 화면에서 이동
```
- 클릭 가능한 요소에 마우스를 올리면 파란색으로 표시됩니다. 상단 '연결 표시'를 켜면 연결된 요소와 미확인 요소를 구분해 볼 수 있습니다.

## Figma와 다르게 처리한 것 (빈 곳 클릭 이동 금지)
Figma에서는 아래 화면의 **화면 전체**가 클릭 영역이었습니다. 빈 곳을 눌러 이동하지 않도록 보이는 버튼에만 연결했습니다.

| 화면 | Figma | 프로토타입 |
|---|---|---|
| 인트로 | 화면 아무 곳 → 목적선택 | '화면을 터치해주세요' 버튼 |
| 행사·매장·근처 팝업, 길안내 앱 보내기, 위치선택 | 화면 아무 곳 → 닫기 | 각 팝업의 '창 닫기' |
| 편의시설 음수대 팝업 | 화면 아무 곳 → 닫기 | 카드 오른쪽 위 ✕ 아이콘 |
| F&B 식당 상세 팝업 | 화면 아무 곳 → 닫기 | 닫기 수단이 없어 ✕ 버튼 보완(주황 점선) |

## 보완한 기능
| 기능 | 동작 |
|---|---|
| 행사조회 캐러셀 | 좌우로 밀면 카드가 돌아가며 가운데 카드가 바뀝니다. 카드를 누르면 Figma대로 해당 팝업이 열립니다. |
| 행사 팝업(오징어게임·전시회·프라다) | 팝업을 좌우로 밀면 이웃한 행사 팝업으로 넘어갑니다('좌우로 슬라이드' 안내 문구 동작). |
| 목록 페이지(1/22) | 매장·F&B·길안내 목록을 좌우로 밀거나 '← 이전 / 다음 →'을 누르면 페이지 번호가 바뀝니다. 다른 페이지는 디자인에 없어 같은 매장을 순서만 바꿔 보여줍니다(테스트 데이터). |
| 편의시설 1/2 → 2/2 | 왼쪽으로 밀면 Figma의 '다음 →' 연결대로 다음 화면으로 갑니다. |
| 스크롤 영역(매거진·행사 팝업 등) | Figma에서 스크롤로 지정한 영역을 손가락·마우스로 끌어 스크롤합니다(관성 있음). 가로 영역은 마우스 휠로도 움직입니다. 끌다가 손을 뗄 때는 카드가 눌리지 않습니다. |
| 지도(층별안내 1F·B1·2F, 평면지도) | Figma에서는 그림뿐이던 지도 버튼이 실제로 동작합니다. ?는 사용법, +/−는 확대·축소, ⤢는 전체 보기, ◎는 현재 위치(빨간 점)로 이동합니다. 마우스 휠이나 두 번 탭으로도 확대하고, 확대한 뒤에는 끌어서 이동합니다. |
| 매거진 '매장 찾기' | 매장 안내에 있는 브랜드(프라다 등)는 매장조회 화면으로 가서 바로 검색합니다. 매장 정보가 없는 브랜드(바쉐론 콘스탄틴)는 버튼을 흐리게 막고, 누르면 이유를 안내합니다. |
| 매거진 진행 막대 | 가로로 넘기면 빨간 진행 막대가 위치를 따라 움직입니다. |
| 화면 키보드(매장·F&B 검색, 길안내) | Figma에서는 그림 한 장이라 키 41개 위치에 터치 영역을 깔아 실제로 입력되게 했습니다. 한글 두벌식 조합(받침 이동·겹받침·지우기), ⬆ 쌍자음, 한/영 전환(키 위에 영문 표시), 띄어쓰기를 지원합니다. |
| 검색 | 입력할 때마다 매장/식당 카드를 통째로 걸러 보여줍니다(영문 브랜드명도 인식). 결과가 없으면 빈 화면 대신 '검색 결과가 없습니다' 안내가 나옵니다. '검색'을 누르면 결과 수를 안내합니다. PC 키보드로도 입력할 수 있습니다. |
| 고대비 ON/OFF | 디스플레이 영역의 대비를 높입니다. |
| 낮은 화면 ON/OFF | 화면 내용 전체를 한 덩어리로 줄여 디스플레이 아래쪽에 모읍니다(휠체어 이용자용). 아래 접근성 버튼 줄은 그대로 둡니다. |
| 글씨크기 크게/보통/작게 | 디스플레이 글자 크기를 조절합니다. |
| 음성크기·음성속도 | 설정값을 저장하고, 지원하는 브라우저에서는 브라우저 음성으로 안내합니다. |
| 언어 | 선택값을 저장합니다(실제 번역은 서버가 필요합니다). |
| 칩·탭·카테고리 | 선택 표시가 이동합니다. 연결 화면이 없는 버튼은 안내 문구를 띄웁니다. |

## 테스트용 vs 실제 서버 필요
- **테스트용(브라우저에서 동작):** 매장·식당 데이터, 검색 결과, 길안내 경로, 음성 안내
- **실제 기기·서버 필요:** 다국어 번역, 실시간 위치·경로 계산, QR로 앱 전송, 실제 음성 안내(TTS 엔진)
